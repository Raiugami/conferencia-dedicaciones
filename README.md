# Conferência Dedicaciones

[Abrir aplicação](https://raiugami.github.io/conferencia-dedicaciones/)

Conferência local de 8 horas por dia útil a partir de PDFs. Os PDFs e sessões da equipe não são enviados ao GitHub.

- [Guia para continuar no Copilot](docs/CONTINUIDADE.md)
- [Instruções do Copilot](.github/copilot-instructions.md)
- [Uso e desenvolvimento](app/README.md)
- [Código editável](app/)

Use Node.js 22. Na pasta app/: npm ci, npm run dev, npm test e npx tsc --noEmit. A publicação automática no GitHub Pages usa os arquivos de app/ e ocorre após mudanças em main. Para novos desenvolvimentos, prefira uma pull request e acompanhe os testes antes de integrar.
